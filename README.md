🕷️ Spiderweb Browser

Spiderweb is a lightweight and modern web browser project designed to provide a simple and user-friendly browsing experience. It uses DuckDuckGo to fetch live web information through the Spiderweb backend.

✨ Features
🔍 Web Search – Search for information using DuckDuckGo.
🌐 Live Information – Displays real-time web information.
📑 Tab Support – Open and manage multiple tabs.
↩️ Navigation Controls – Back, forward, and refresh options.
🔒 Secure Browsing – Includes a secure browsing indicator.
🎨 Modern UI – Clean dark-themed browser interface.
⚡ Fast & Lightweight – Designed for simple and efficient browsing.
🛠️ Technologies Used
HTML – Structure of the browser interface
CSS – Styling and responsive UI
JavaScript – Browser functionality and interactions
Backend – Handles web requests and search processing
DuckDuckGo – Web search and information source

🚀 How to Run
1. Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL
2. Open the project
cd Spiderweb
3. Install dependencies
npm install
4. Start the application
npm run dev
5. Open in browser

Visit:

http://localhost:5173
🎯 Project Goal

The goal of Spiderweb is to create a simple browser-like application that combines a modern browsing interface with web search and live information retrieval.
